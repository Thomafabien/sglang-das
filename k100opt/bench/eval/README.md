# 精度评测脚本

判定要求：gsm8k、humaneval、math-500 三项精度相对优化前下降不超过 1 个百分点。

| 脚本 | 用途 |
|---|---|
| `evalscope_run.sh` | **正式口径**：实验室给出的 evalscope 命令（思考模式、temperature 1.0、max_tokens 163840）。全量一次约 5–6 小时，思考链很长；抽样（100 / 80 / 16×5 题）约 40 分钟 |
| `gsm8k_full.py` | 自测口径的 gsm8k 全量（1314 题，5-shot，关闭思考），约 5 分钟，用于改动前后的快速对照。绝对值与 evalscope 口径不可比 |
| `long_gsm8k.py` | 把 gsm8k 题目嵌入指定长度的上下文（如 16000 / 32000 / 66000 token），检验只在长输入上生效的改动（通信量化、分块方式） |
| `sentinel.py` | 真实文本长上下文上的投机解码接受长度与输出一致性；接受长度下降说明数值路径受到影响 |

注意：temperature 1.0 下单次评测有随机波动（164 题的 humaneval 一道题就是 0.6 个百分点），对照时两臂必须用同一批题与同一 `--seed`，必要时重复取均值。
`math_500` 的 `--limit` 按难度档计数（共 5 档）。
